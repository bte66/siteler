# Granicus Aktar — güncellemeler

Bu klasörü Granicus Aktar programı otomatik güncelleme için okur.

- `guncelleme.json`: en son sürüm, imzalı. Program yalnızca Granicus anahtarıyla imzalanmış dosyaları kabul eder.
- `GranicusAktar-Kurulum-<sürüm>.exe`: kurulum dosyası. Depo büyümesin diye yalnızca son sürüm burada tutulur.
